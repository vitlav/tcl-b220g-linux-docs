# Дополнительное исправление LPASS runtime-PM из qc7

Сохранён исходный патч **Nikita Travkin** `283c8d3f8579db2d3698b1e2c668a62e04a7090a`: отключение macro/dcodec clocks в VA macro runtime suspend и их включение при resume. Авторство, сообщение и исходный Signed-off-by сохранены без изменения. Содержимое файла совпадает с оригиналом в архиве qc7.

## Применимость

Патч проверен на итоговом ACPI-дереве основной серии, коммит `f8c7009045bb8912ee9d160feafa0136fe9da095`. `git apply --cached --check` и применение во временном индексе прошли без изменений патча. [Манифест](manifest.json) содержит хеш исходного патча, базового и полученного дерева. Это проверка применения, а не сборка или аппаратная проверка.

[series](series) относится только к этому дополнительному набору, который применяется **после основной ACPI-серии**. В основной series патч не включён; работающий ноутбук не изменён.

## Перед включением в рабочую сборку

Проверить баланс включения/отключения macro/dcodec при probe, runtime suspend/resume и remove, частичные ошибки включения clocks, повторные циклы PCM и совместимость с используемыми power-hold провайдерами. Применимость diff сама по себе не доказывает корректность этих переходов.

## Исправления, требующие адаптации

- `2637dc2cbba04da60fce3156902ba0611a4b30a8`: Q6AFE client_handle tracking. Исходный патч не прикладывается к текущему `q6afe.c`.
- `dfa7b00cc17dbb0a3767a8eee5eeb116f50267ff`: LPI suspend/resume. Исходный патч не прикладывается к текущему `pinctrl-sc7280-lpass-lpi.c`.
