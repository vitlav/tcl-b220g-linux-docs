# ACPI: Linux 7.2.4 для TCL B220G

Самостоятельная серия из **42 патчей** к Linux stable **v7.2.4**, база `5015d0d945b3d3f2b038d2667880d5762f7d9437`. Включает ACPI-поддержку USB/Wi-Fi, дисплея/GPU, аудио и стандартного power_supply для EC. Серии DT и qc7 перед ней не требуются.

Это снимок исходников текущей разработки. На рабочей ACPI-системе подтверждены Ubuntu 26.04.1 LTS и ALT Linux, Wi-Fi/SSH, ввод, нативный MSM framebuffer, Wayland/Adreno, слышимое воспроизведение и BAT0/ADP1 через standard power_supply. Патчи 38–40 собраны вместе в рабочем дереве и проверены на оборудовании: исчезло неверное позднее переназначение PM-domain GPU SMMU, I2C3 привязался, BAT0 и ADP1 появились автоматически. Патчи 41–42 исправляют выгрузку LPASS macro: VA/RX/TX и SoundWire полностью выгружены и повторно подключены без PM warning, Oops или trace; карта, оба кодека и слышимый звук восстановились.

Полная сборка `Image modules` точного 42-патчевого дерева прошла с приложенной конфигурацией `7.2.4-tcl-acpi-standard3+`. Конфигурация синхронизирована с реально загруженным ядром и включает UFS, ramoops/pstore и его фактический localversion. Получены Image SHA256 `b7daaf79...d74394` и 956 модулей. **Аппаратная загрузка именно собранного полного снимка ещё требуется.** Совпадение строки версии ядра и отдельных модулей не доказывает совпадение установленного Image со всем опубликованным деревом.

## Происхождение базы

База серии — Linux stable v7.2.4 (`5015d0d945b3d3f2b038d2667880d5762f7d9437`), а не qc7. Полный diff между этой базой и целевым деревом входит в series; предварительно применять сторонние qc7-патчи не требуется. Их отдельный каталог относится к [DT-базе](../dt/base-patches/README.md).

Чистая база не означает отсутствие обходных решений в самой серии. Зависимость дисплея от firmware handoff, специальные описания ресурсов и внешние аудиопровайдеры остаются ограничениями реализации. Логическое разделение патчей не подтверждает их готовность к upstream.

Подтверждённый перенос решения Stephen Boyd для отключения ROT выделен в патч №22 с исходным авторством и описанием адаптации. [Сопоставление qc7 и текущей ACPI-серии](../../../research/qc7-provenance/acpi-attribution.md) различает переносы, отсутствующие изменения и нерешённые вопросы происхождения.

## Логическое разделение

Каждый патч содержит законченное изменение и его описание: причина, механизм и границы применимости. Исправления общего кода (ACPICA, firmware-node graph, remoteproc, MSM pagetable/fbdev, interconnect) отделены от адаптации драйверов и описания устройств TCL. Порядок учитывает зависимости API, поставщиков ресурсов и потребителей.

Сетевые связи устройств описаны отдельно от дисплея/GPU. Проверки ошибок включены непосредственно в соответствующие реализации. Повторное изменение общего файла допустимо для разных задач: например, исправление BCM и поддержка firmware-node поставщиков interconnect. Kconfig и Makefile дополняются при добавлении соответствующих драйверов.

[Перечень по назначению](patches/README.md) объясняет состав серии. Проверка применения подтверждает итоговое дерево; сборка каждого промежуточного коммита отдельно пока не проверена.

## Воспроизведение

[series](patches/series) задаёт порядок, [commits.txt](commits.txt) содержит настоящие SHA коммитов, [manifest.json](manifest.json) — базу, итоговое дерево, SHA256 патчей и конфигурации. Последовательное применение всей серии к чистому индексу базового коммита воспроизводит исходное дерево побайтно: [результат](patch-replay.txt).

В чистом checkout указанной базы:

```sh
patch_dir=/path/to/tcl-b220g-linux-docs/patches/kernel/acpi
(
    set -eu
    git switch -c tcl-acpi
    while IFS= read -r patch_name; do
        git am "$patch_dir/patches/$patch_name"
    done < "$patch_dir/patches/series"
    cp "$patch_dir/kernel.config" .config
    make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- olddefconfig
    make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- -j16 Image modules
)
```

Используйте приложенную фактическую конфигурацию: ранний `tcl_acpi_defconfig` внутри серии не заменяет конфигурацию мультимедийной сборки. Image, modules, внешние модули и initramfs должны собираться и устанавливаться согласованно. Команда выше только собирает ядро.

## Системные зависимости

Аудио дополнительно требует [внешних модулей](modules/README.md) и [системных служб](../../../system/acpi/README.md), OEM firmware, корректных mixer state, питания и pinctrl. Для доступа нужны firmware/службы Qualcomm, Wi-Fi, DHCP и SSH. Серия ядра сама по себе не является готовым установочным образом. Приватные ключи и Wi-Fi-пароли в репозиторий не входят.

## Ограничения

Нативный дисплей ещё зависит от UEFI handoff. Аудио использует отдельные board-specific providers, штатная интеграция питания и жизненного цикла не закончена. Повторяемые cold boot, suspend/resume, unload/reload и корректность аппаратного видеодекодирования должны пройти [план проверки](../../../docs/roadmap.md). Состояние звука описано [отдельно](../../../docs/hardware/audio-acpi.md).

## Сохранённые дополнительные исправления

[LPASS runtime-PM из qc7](optional-patches/lpass-pm/README.md): исходный патч Nikita Travkin прикладывается к итоговой ACPI-базе без изменений. Он сохранён отдельно с авторством и манифестом; перед включением нужны проверка логики переходов питания, сборка и аппаратные тесты. Основной series его пока не содержит.
