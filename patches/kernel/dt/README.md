# DT: сохранённые изменения ядра

Рабочий эталон описан для `6.18.34-tcl-audio2` на базе qc7. [Патчи](patches/) разделены на `audio/` и `graphics/`; [манифест](manifest.json) сохраняет описание и происхождение файлов. Это каталог сохранённых изменений, включая альтернативные и диагностические варианты, а не полная последовательная серия к чистой базе. Файла `series` нет: порядок применения не установлен.

[Внешние модули](modules/README.md) и [системные материалы](../../../system/dt/README.md) описаны отдельно. Конфигурации и DT находятся в существующей [документации сборки](../../../docs/kernel-and-ubuntu.md) и [полном перечне DT](../../../docs/hardware/full-inventory.md).

При упорядочении каталога содержимое патчей не изменялось. Проверки DT, сборка и загрузка в рамках этой работы не выполняются.
