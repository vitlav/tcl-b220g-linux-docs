# Внешние изменения исходной DT-базы qc7

Здесь отдельно сохранены сторонние изменения qc7, предшествующие нашим TCL-адаптациям. Источник — рецепт hexdump0815 для SC7180, коммит `3fbde69c6a0b31e7cba94b036301c003723c3c31`, использованный для исходной сборки `6.18.34-stb-qc7+`. Наши изменения находятся в [../patches/](../patches/).

| Файл | Назначение |
|---|---|
| [travmurav-changes-v6.12.patch](travmurav-changes-v6.12.patch) | Адаптированный объединённый патч из рецепта qc7 для 6.18; имя файла сохранено из источника |
| [add-gamma-lut-support.patch](add-gamma-lut-support.patch) | Поддержка gamma LUT дисплея |
| [add-new-dts-files-to-makefile.patch](add-new-dts-files-to-makefile.patch) | Включение дополнительного Samsung DTS в сборку |
| [travmurav-original-commits.mbox](travmurav-original-commits.mbox) | Исходные 16 коммитов TravMurav с авторством и описаниями; справочный оригинал объединённого патча |
| [manifest.json](manifest.json) | Источники и сохранённые хеши |

Mbox и адаптированный объединённый патч — разные представления связанных изменений, их нельзя применять вместе. Не все сторонние изменения являются хаками: среди них есть функциональная поддержка, конфигурации и явно помеченные HACK/FIXME/REVERTME решения. Подробный [перечень и происхождение](../../../../research/qc7-provenance/README.md) позволяет различить их.

Это выделение уже сохранённых файлов по происхождению, а не восстановленный полный рецепт qc7. Рецепт также использует DTS, конфигурационные фрагменты и исправление суффикса версии, описанные в справочнике. Здесь не задан новый series; применимость и сборка DT при выделении каталога не проверялись.

К текущей ACPI-серии этот слой не применяется: её база — чистый Linux v7.2.4. Наличие похожего решения в ACPI требует отдельного сопоставления кода, а не автоматического переноса всего qc7.
