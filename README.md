# Linux на TCL Book 14 Go / B220G

Техническая спецификация ноутбука на Qualcomm SC7180 (Snapdragon 7c), состояние на **10 сентября 2026 года**. Оборудование, ресурсы устройств, интерфейсы firmware и требования к поддержке Linux. Для результатов указана степень подтверждения.

**Рабочая конфигурация — Ubuntu, загрузка через UEFI и Device Tree, ядро Linux `6.18.34-tcl-audio2` с патчами для TCL B220G.** Полноценная загрузка через OEM ACPI пока не достигнута.

## Проверено на оборудовании

- Ubuntu с USB, Wi-Fi и SSH; внутренний UFS доступен, Windows сохранён в резервном архиве.
- Нативный вывод через MSM/DPU/DSI и LT8911EXB, GPU Adreno 618, Wayland и графические тесты.
- Видеодекодирование Venus проверялось отдельно от GPU-вывода; воспроизведение mpv требует правильного выбора декодера.
- Звук через ADSP, SoundWire и WCD9385 получен и подтверждён на слух. Восстановление тракта и ошибки повторного запуска исследуются отдельно.
- Данные батареи читаются через EC; стандартного полноценного драйвера EC/power_supply ещё нет.

Это результаты отдельных проверенных этапов, **не гарантия автозапуска всех функций в любом экспериментальном пункте GRUB**. Применимость определяется конфигурацией ядра, DT и набором патчей.

`docs/` — спецификация и сводки поддержки; `research/` — технические обоснования, DT и исходники проверок; `artifacts/` — манифесты. Код в `research/` сохранён для исследования и не устанавливается автоматически.
