# Linux на TCL Book 14 Go / B220G

Документация исследования ноутбука на Qualcomm SC7180 (Snapdragon 7c), состояние на **10 сентября 2026 года**. Здесь собраны подтверждённые результаты, необходимые изменения Linux, описание оборудования и журнал экспериментов.

**Рабочая основа — Ubuntu с UEFI + Device Tree и собственным ядром `6.18.34-tcl-audio2`. Это не неизменённое штатное ядро Ubuntu.** Полноценная загрузка через OEM ACPI пока не достигнута. Текущая MEMDIAG-сборка сохраняет тот же kernel release, но отличается настройкой доступа к памяти.

## Проверено на оборудовании

- Ubuntu с USB, Wi-Fi и SSH; внутренний UFS доступен, Windows сохранён в резервном архиве.
- Нативный вывод через MSM/DPU/DSI и LT8911EXB, GPU Adreno 618, Wayland и графические тесты.
- Видеодекодирование Venus проверялось отдельно от GPU-вывода; воспроизведение mpv требует правильного выбора декодера.
- Звук через ADSP, SoundWire и WCD9385 получен и подтверждён на слух. Восстановление тракта и ошибки повторного запуска исследуются отдельно.
- Данные батареи читаются через EC; стандартного полноценного драйвера EC/power_supply ещё нет.

Это результаты отдельных проверенных этапов, **не гарантия автозапуска всех функций в любом экспериментальном пункте GRUB**. Сверяйте дату, boot ID и конкретную сборку.

`docs/` — актуальная навигация и сводки; `research/` — тематические первичные отчёты, DT, патчи и экспериментальные исходники; `history/` — журнал; `artifacts/` — манифест архива. Код в `research/` сохранён для исследования и не устанавливается автоматически.
