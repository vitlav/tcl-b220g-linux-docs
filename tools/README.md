# Проверка набора firmware

`check-firmware.py` только читает указанный каталог и сравнивает файлы с архивным и установленным поднаборами из `artifacts/firmware-*-manifest.json`. Два манифеста дают 25 уникальных путей: 11 основных эталонов и 14 вариантов OEM board data. Полный MPSS-кандидат без пути установки исключён.

```sh
python3 tools/check-firmware.py /путь/к/rootfs/usr/lib/firmware
```

Результат — JSON в stdout. Код завершения 0 означает совпадение 11 основных эталонов; 1 — отсутствие, отличие или ошибка чтения хотя бы одного из них. Ошибки аргументов имеют код 2. Для каждого пути указаны `match`, `missing`, `different` или `error`, фактические размер/SHA256, выбранное имя и присутствующие альтернативы.

Отсутствие/отличие 14 дополнительных `bdwlan*`/`bdwlanu*` отражается в JSON, но не меняет код завершения. Это политика проверки сохранённого поднабора, а не доказательство, что эти файлы не нужны конкретной firmware. Выбор board-2 контейнера проверяется [отдельно](../research/firmware-upstream/ubuntu-board-selection.md); инструмент не исполняет алгоритм ath10k.

Проверяется обычное имя, при его отсутствии `.zst`, затем `.xz`; обычный файл с неправильными байтами не маскируется правильной сжатой копией. Для Zstandard нужен `zstd` в PATH, XZ поддерживает стандартный Python `lzma`. Символические ссылки разрешаются в текущей файловой системе: для офлайн rootfs абсолютные ссылки следует рассматривать отдельно, это не chroot-проверка. Ошибка чтения существующего пути не считается его отсутствием.

Команда не устанавливает пакеты, не меняет firmware, не перезапускает службы, не проверяет подписи, kernel/DT/initramfs, аппаратную загрузку DSP и индивидуальные RMTFS-данные. Код 0 не означает готовность всего образа к загрузке. Необходимо также проверить [состав Ubuntu](../docs/ubuntu.md) и [границы воспроизводимости](../docs/validation-gaps.md#воспроизводимость-комплекта).

Проверены: совпадение всех 25 файлов с архивными/публичными эталонами; отсутствие дополнительных вариантов; XZ/ZSTD fallback; приоритет отличающегося обычного файла; повреждённая ссылка; ошибка ZSTD-потока. Эти проверки выполнены в отдельных временных каталогах, без изменения ноутбука.
