## Дополнение 2026-09-09: актуальные результаты DT и новые подзадачи

Задача ACPI уже существует; дубль не создаётся. Основная задача #19084. ACPI остаётся отдельным направлением и не останавливает доводку звука в DT.

### Изменения относительно исходного описания

- Звук через WCD9385 и внешние динамики уже слышен: пользователь подтвердил тестовый сигнал и фильм, в том числе достаточную громкость. Поэтому воспроизведение звука теперь входит в функциональный baseline для ACPI. Микрофон ещё не проверен, постоянная интеграция звука в систему не завершена; PulseAudio для Firefox сейчас готовится.
- Для усилителя по соответствующему OEM AUDD_CLS_7180 (SUBSYS27822202) подтверждены GPIO46/47; отдельное включение после запуска PCM позволило услышать звук. GPIO58 reset проверен отдельно; запрет слепого обхода59–62 остаётся.
- Найден и исправлен в тестовых модулях порядок освобождения IRQdomain/regmapIRQ и SoundWire callback, проверены повторные циклы. Отдельный Q6ASM prepare после STOP ранее пропускал закрытие сессии/отображения и приводил к ADSP_EALREADY; кандидат исправления прошёл3цикла drop/prepare и seek в mpv после чистой загрузки. Это диагностические патчи, не утверждение о полном устранении всех ошибок.
- При закрытии mpv пользователь слышит щелчок; обнаружено, что PA выключался после закрытия PCM. Для постоянного решения нужна согласованная последовательность PA/PCM/DAPM, включая EOF/ручное закрытие. Учесть это при переносе ACPI питания.

### GPS / модем — #19500

Windows Hardware ID ACPI VEN_QCOM DEV_081E SUBSYS_CLS07180 выбирает OEMсекцию MSM и qcmpss7180.mbn; Linux пока использует qcmpss7180_nm.mbn для Wi-Fi. Полный вариант содержит обработчики QMI_LOC и gps/gps_service, в текущем QRTR LOC/PDS отсутствуют.

| Вариант | Резерв от0x86000000 | Файл |
|---|---|---|
| NM/APQ активный |32MiB, до0x87ffffff|5057288байт|
| Полный MSM OEM |132MiB, до0x8e3fffff|61815992байт|

Полные PT_LOAD проверены; диапазон не пересекается с Venus, ADSP, WLAN, но пересекает унаследованный IPAreserve0x8b700000/64KiB в DT (IPAdisabled, потребителя нет). Это отдельный вопрос правильного описания памяти и выбора прошивки, который ACPI-порт должен учитывать. GPSfix не получен; не считать готовым.

### Датчики / крышка — #19501

Windows видит Aw9610x Sar Sensor (ACPI AWDZ9610X) и ACPI Lid/PNP0C0D. DSDT SAR1: I2C5 addr0x12/400kHz, GPIO34 EdgeBoth/PullUp, _STA0x0f; DSM содержит AW96105 и OEM конфигурацию0x37cбайт. В Linux6.18.34 aw96103.c уже поддерживает awinic,aw96105; ACPI binding/настройки ещё не проверены. Для крышки нужен рабочий SW_LID и корректные notifications. Акселерометр/гироскоп/компас по Windowsinventory не найдены, физическое отсутствие не доказано.
