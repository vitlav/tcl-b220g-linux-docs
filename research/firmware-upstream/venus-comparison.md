# Venus: Ubuntu 00063 и рабочая 00064

**Проверено по файлам:** установленная на TCL `qcom/venus-5.4/venus.mbn` побайтно совпадает с ранее сохранённой firmware и исследованным upstream linux-firmware. DEB graphics содержит другую версию. Файлы на TCL не менялись, декодер не перезапускался.

| Свойство | Установленный файл / upstream | Ubuntu graphics DEB |
|---|---|---|
| Version string | VIDEO.VE.5.4-00064-PROD-1 | VIDEO.VE.5.4-00063-PROD-1 |
| Строка даты в бинарнике | Jul 1 2026 | Dec 19 2025 |
| Размер после распаковки | 922376 байт | 922312 байт |
| SHA256 | `db2a2efefa7149519b36f01be8a7c37bdf21efd2f06eff5028f80d4295aef7d9` | `3148b6a909ac854fba785148b684b38fc9c268a82aaf9c905f310fc700c8ad88` |

Версии извлечены из строки QC_IMAGE_VERSION_STRING внутри ELF. Дата — строка сборки, не время установки или загрузки драйвером. [Сегменты, версии и суммы](venus-comparison.json).

## Структурное сравнение

Оба файла ELF32 little-endian, по пять program headers. Первый PT_LOAD (индекс 2) имеет тот же физический адрес 0x0f500000; filesz/memsz уменьшаются с 876160 до 876096 байт в Ubuntu. Последующие файловые offsets сдвинуты на 64 байта, их физические адреса не меняются. Payload сегментов 1, 2 и 3 различаются; последний 32-байтовый payload совпадает. Это другая сборка firmware, не только отличие сжатия или удаление хвостового padding.

Разбор ELF не устанавливает, какие именно исправления содержит 00064. Более высокий номер не доказывает устранение наблюдавшихся ошибок декодирования; аппаратное сравнение 00063/00064 не выполнено. Ограничения работающей версии перечислены в [спецификации Venus](../../docs/hardware/video.md).

## Одновременное наличие .mbn и .mbn.zst

В коде Linux 6.18.34 `drivers/base/firmware_loader/main.c` файловая загрузка сначала проверяет исходное имя, и лишь при ENOENT пытается `.zst`, затем `.xz`. Поэтому при обычном запросе `qcom/venus-5.4/venus.mbn` сохранённый несжатый файл 00064 имеет приоритет перед пакетным `.mbn.zst` 00063. Это вывод по коду, а не проведённый тест установки пакета.

При переносе на новый образ или удалении несжатой копии результат изменится: тогда пакет может предоставить 00063. Установка graphics сама по себе не переводит существующую несжатую 00064 под управление dpkg. В воспроизводимом комплекте необходимо явно фиксировать выбранный файл, а не считать имя пакета достаточным описанием версии Venus.
