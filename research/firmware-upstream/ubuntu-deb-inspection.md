# Содержимое Qualcomm DEB Ubuntu

Проверены кандидаты из пакетной базы Ubuntu TCL: graphics `20260319.git217ca6e4-0ubuntu1.1`, wireless `20260319.git217ca6e4-0ubuntu1.2`, misc `20260319.git217ca6e4-0ubuntu2.1`. DEB скачаны на рабочую машину, суммы совпали с SHA256 из APT metadata. Пакеты не устанавливались, их maintainer scripts не исполнялись.

[Метаданные, суммы DEB и выбранных распакованных файлов](ubuntu-deb-inspection.json). Содержимое `.zst` сравнивалось после декомпрессии; сравнение только сжатых потоков было бы недостаточным.

## Влияние на установленный комплект

В MEMDIAG включены CONFIG_FW_LOADER_COMPRESS, CONFIG_FW_LOADER_COMPRESS_XZ и CONFIG_FW_LOADER_COMPRESS_ZSTD. Ядро поддерживает формат пакетных файлов.

Проверка всех firmware file/link paths из graphics и wireless на TCL не обнаружила существующих объектов по точно таким же путям. Это объясняется, в частности, отдельными `.zst`-именами. Она не означает отсутствия поведенческих изменений: ath10k сначала пытается использовать board API2 (`board-2.bin`), а затем переходит к API1 (`board.bin`). Добавленный контейнер может изменить выбор board data при следующем запуске драйвера, даже если OEM board.bin не перезаписан.

[Пакетный board-2 сопоставлен с идентификаторами TCL](ubuntu-board-selection.md): по коду выбирается generic board-id=ff, payload совпадает с текущим board.bin. Аппаратная загрузка API2-контейнера пока не проверена.

## Сценарии установки и initramfs

У всех трёх пакетов postinst на `configure` выполняет `dpkg-trigger --no-await update-initramfs`. В проверенной системе пакеты initramfs-tools и initramfs-tools-core отсутствуют, файл регистрации `/var/lib/dpkg/triggers/update-initramfs` отсутствует, `/boot` пуст. Таким образом, сохранённый вручную загрузочный initramfs на USB не становится автоматически обновлённым от установки этих DEB.

Прямого запуска update-initramfs в postinst нет. Поведение может измениться после установки соответствующего обработчика, поэтому нельзя переносить этот вывод на любой Ubuntu-образ.

## Выбор состава

Полный linux-firmware не помещается в текущий корень. Graphics занимает около 10.5 МиБ и содержит точные аналоги GPU SQE/GMU, но его Venus отличается. Wireless занимает около 46.6 МиБ; требуется проверка выбора board API2. Misc занимает около 159.6 МиБ и пока не предоставляет установленного решения для OEM DSP TCL. Установка любого из этих пакетов не заменяет индивидуальные RMTFS-данные и OEM MPSS/ADSP/secure GPU firmware.

Эта проверка подготовила оценку состава, а не выполнила установку или аппаратную проверку новых firmware.
