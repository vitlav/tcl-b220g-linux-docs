# Источники маршрутов дисплея SC7180

Сохранены оригинальные `drivers/interconnect/qcom/sc7180.c` двух используемых ветвей Linux, с заголовками лицензии:

- [6.18](sc7180-6.18.c): таблица из семейства ядра, на котором проверен DT-дисплей.
- [7.2.4](sc7180-7.2.4.c): таблица ванильного ядра из проверенной ACPI-базы v7.2.4 (`5015d0d945b3d3f2b038d2667880d5762f7d9437`).

[Маршруты и SHA256](paths.json) фиксируют обе цепочки. Все соседние пары узлов проверены по обоим исходникам; связи совпадают. В 6.18 рёбра заданы числовыми идентификаторами `SC7180_*`, в 7.2.4 — указателями `link_nodes`. Идентификаторы DT endpoints и внутренние идентификаторы драйвера не следует смешивать.

Конечные точки `mdp0-mem` и `cpu-cfg` уже присутствуют в [снимке рабочего DT](../../docs/hardware/live.dts). Промежуточные переходы выбирает ICC framework по таблицам драйвера. Успешный DT-вывод подтверждает работу всей конфигурации; отдельного измерения потока на каждом промежуточном узле не проводилось.

Спецификации: [DT](../../docs/hardware/display.md), [ACPI](../../docs/hardware/display-acpi.md). Физические связи относятся к SC7180; способ описания и состояние Linux-поддержки указаны отдельно.
