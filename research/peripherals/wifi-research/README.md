# Исходники для анализа ath10k / Qualcomm WLAN

Актуальное описание ресурсов, питания, firmware и подтверждённой работы — [спецификация Wi-Fi](../../../docs/hardware/wifi.md).

Сохранённые C-файлы позволяют проследить SNOC probe, QRTR/QMI, remoteproc и RMTFS. В частности, ath10k передаёт board data через QMI после подготовки MSA; tqftpserv обслуживает другой интерфейс запросов DSP. Успех probe и наличие daemon не заменяют проверку готовности WLAN.

Файлы с именем v6.18 — исходники соответствующей upstream-базы. Они не доказывают побайтовую идентичность модифицированному ядру TCL. Acer DTS служит сравнительным описанием другой платы; его board IDs и питание не следует переносить без сверки.
