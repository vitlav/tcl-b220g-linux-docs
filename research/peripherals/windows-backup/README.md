# Резервная копия внутренних UFS LUN

[Модель накопителя, размеры LUN и границы проверки](../../../docs/hardware/storage.md#логические-устройства).

Проверенный архив содержит полные образы шести доступных Linux LUN, включая GPT и свободное пространство. Формат — Borg 1.4.5, без шифрования, сжатие zstd,3 и дедупликация. Источники при копировании read-only и не смонтированы. RPMB и прочие не предоставленные Linux области не включены.

Полное извлечение каждого потока сверено по SHA256, проверка репозитория Borg завершена успешно. Восстановление на накопитель и последующая загрузка Windows не испытаны.

Архив содержит индивидуальные данные Windows и служебных разделов и хранится отдельно от публичной документации. Идентификация назначения при восстановлении требует контроллера, LUN, модели и размера; буква /dev/sdX недостаточна.
