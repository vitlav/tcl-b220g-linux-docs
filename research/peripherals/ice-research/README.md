# Qualcomm Inline Crypto Engine

[Спецификация ICE](../../../docs/hardware/storage.md#ice-подтверждённые-возможности) фиксирует аппаратную версию, keyslots, алгоритм, интерфейсы ядра и границы проверки.

ICE v3.1.75 инициализирован на TCL; зашифрованное I/O не проверено. [Конфигурация ICE1](ice1/kernel.config) и исходники проверки сохранены для сопоставления реализации. Обычный UFS и пользовательский Crypto API описаны отдельно от inline encryption.
