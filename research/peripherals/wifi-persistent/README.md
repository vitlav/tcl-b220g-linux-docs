# Автоматическое подключение WLAN

[Спецификация Wi-Fi и подтверждённые возможности](../../../docs/hardware/wifi.md). Автоматическое подключение без телефона подтверждено после перезагрузки как для диагностического initramfs, так и для Ubuntu.

Файлы в этом каталоге относятся к диагностическому initramfs с BusyBox udhcpc и Dropbear. Они не являются конфигурацией служб Ubuntu; [Ubuntu использует networkd и OpenSSH](../../../docs/ubuntu.md#сеть-и-доступ). Сборочные скрипты содержат параметры конкретного носителя и окружения и требуют адаптации.
