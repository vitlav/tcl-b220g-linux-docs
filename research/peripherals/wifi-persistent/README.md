WLAN имеет метрику 100, USB — 500; правила по адресу источника обеспечивают симметричные ответы через каждый интерфейс. DNS берётся из DHCP WLAN. Текущий адрес 192.168.8.177 выдан DHCP, не задан статически.

Wi-Fi не зависит от успешного сохранения логов на USB. Логи сохраняются раз в 5 минут. Автоматический запуск нового пункта GRUB через 5 секунд; прежние пункты сохранены.

Проверены синтаксис скриптов, CPIO, права 0600 на секреты, наличие утилит и библиотек. DHCP hook проверен на работающем устройстве продлением аренды. Холодный старт нового образа ещё не проверен: текущую рабочую сессию не перезагружали.
