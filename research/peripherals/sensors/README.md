# Датчики TCL

[Спецификация AW96105 и крышки](../../../docs/hardware/sensors.md). AW96105 измеряет меняющиеся raw-значения через IIO; питание, физические электроды и события ещё требуют проверки.

Сохранённые aw96103.c и tcl_sar_client.c относятся к изученному ядру и временному подключению; не являются завершённой постоянной интеграцией.
