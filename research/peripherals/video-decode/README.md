# Qualcomm Venus и видеодекодирование

[Спецификация Venus](../../../docs/hardware/video.md) содержит ресурсы, firmware, матрицу проверки H.264, CPU-сравнения и ограничения mpv. Аппаратное декодирование подтверждено, но не все режимы корректны.

[Камера USB UVC](../../../docs/hardware/camera.md) — отдельное устройство; живое изображение подтверждено. Детальные исходники тестов сохранены в подкаталогах.
