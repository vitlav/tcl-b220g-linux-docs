# Wayland на TCL: цель и текущие ограничения

Пользователь уточнил, что конечная цель — Wayland на встроенном экране. EFI framebuffer позволяет программный вывод, но демонстрационная картинка не является Wayland и не проверяет ускорение.

В сохранённой конфигурации используемого ядра6.18.34-stb-qc7+:

```
CONFIG_SYSFB=y
# CONFIG_SYSFB_SIMPLEFB is not set
# CONFIG_DRM_SIMPLEDRM is not set
```

modinfo simpledrm на устройстве возвращает not found. Драйвер не собран, его нельзя просто включить modprobe. /proc/config.gz и /boot/config соответствующей версии отсутствуют; источник config — ../.. /kernel-6.18.34-config.txt, сохранённый для этой сборки. Само наличие platform driver simple-framebuffer не означает simpledrm: текущий вывод — EFI VGA/efifb.

Промежуточный путь: вариант ядра с CONFIG_SYSFB_SIMPLEFB=y и CONFIG_DRM_SIMPLEDRM=y при сохранении остальных проверенных параметров. Проверить итог Kconfig и зависимости; простое редактирование текстового config недостаточно. Нужны совместимые модули/initramfs и отдельный пункт загрузки. Пакетную сборку направлять сборщику пакетов согласно правилам проекта, самостоятельно пакет не пересобирать.

После появления DRM card/connector через simpledrm — пробовать Weston DRM backend с pixman renderer, сначала временно на отдельной VT. Официальная документация: https://wayland.pages.freedesktop.org/weston/toc/running-weston.html . Конкретные CLI-флаги сверять с установленной версией. Пакеты устанавливать через epm. Это CPU rendering с фиксированным framebuffer UEFI; управление панелью, suspend и Adreno GPU остаются отдельными задачами.

Полный путь: native MSM/DPU/DSI + LT8911EXB DRM bridge, затем GPU/Mesa. Подтверждённые I2C/ID/timing/link параметры лежат в ../graphics-probe/ и ../graphics-research/.

show-fb-test.py — отдельная обратимая демонстрация через /dev/fb0,30секунд. Проверяет геометрию/формат/активную текстовую VT, сохраняет framebuffer, временно переводит VT в KD_GRAPHICS, выводит полосы/сетку/надпись и в finally восстанавливает экран/KD_TEXT. Не трогает мостик, DT, GRUB или пакеты. Проверка пользователем фактического изображения нужна отдельно от успешного выполнения скрипта.

Результат2026-09-08: DISPLAYING и RESTORED получены, SSH-процесс завершился0. Пользователь подтвердил «всё отлично!» после показа. Программный визуальный вывод проверен, консоль восстановлена. Это пока не Wayland и не GPU acceleration.

## Уточнение приоритета пользователя

Пользователь: «Наверное, simpledrm не интересно». Ветку отдельного ядра simpledrm откладываем; сборку не запускали. Приоритет — native MSM/DPU/DSI + LT8911EXB, затем GPU/Wayland. Программная демонстрация EFI уже проверена и не является целью дальнейших работ.
