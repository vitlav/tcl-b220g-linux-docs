# LT8911EXB: firmware handoff

Handoff проверен на оборудовании для нативного MSM/DPU-вывода. Полный cold-start не реализован. Исходник tcl_lt8911_handoff.c описывает действующий тестовый bridge; first-test-v1.c — предыдущий вариант.
