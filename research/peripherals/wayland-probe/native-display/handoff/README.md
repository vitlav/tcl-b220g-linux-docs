# LT8911EXB: диагностический firmware handoff

2026-09-08. Исходник подготовлен и скомпилирован только в ARM64 .o, W=1 без предупреждений. На TCL не устанавливался. Это не полноценный драйвер LT8911EXB и не готовый загрузочный комплект.

Цель: проверить DPU → DSI → уже настроенный UEFI мост → панель, прежде чем реализовывать полный cold-start моста. Модуль не пишет GPIO, reset, PLL, link training, тайминги или регуляторы; единственные I2C writes — выбор банка FF с окончанием в 81. Probe проверяет ID 17:05:E0 и сохранённые D0/A8 timing registers. Разрешён один режим 1920×1080, 142520 kHz, H1978/2020/2080, V1083/1088/1142. Полярности +H/+V взяты из первого DTD сохранённого display-edid.bin (byte71=1f; те же флаги интерпретирует drm_edid.c), а не из успешной компиляции. Режим DSI: четыре линии RGB888, non-burst sync event. Continuous clock пока экспериментальный выбор.

MSM регистрирует DSI host до component bind, ищет bridge через port1/endpoint0 и использует NO_CONNECTOR. Поэтому регистрация bridge до mipi_dsi_attach соответствует его порядку запуска. eDP connector без detect callback считается подключённым drm_bridge_connector; это не физическая проверка линка.

## Что ещё необходимо до загрузки

- Получить согласованные kernel headers/exports/toolchain или собрать единый kernel+module комплект. Сейчас нет Module.symvers, отличается toolchain/config и kernelrelease; compile-only не решает ABI.
- Подготовить и проверить DT: MMSS NoC, DISPCC, MDSS, DSI/PHY, их supplies и двусторонний graph до I2C bridge. Compatible tcl,b220g-lt8911exb-handoff-test только экспериментальный, upstream binding отсутствует.
- Проверить сохранение питания моста/панели: отсутствие записей этим модулем не предотвращает отключение unused regulators/clock ядром. OEM PRM таблицы помогают, но не заменяют карту физических цепей.
- Исключить параллельные raw I2C bank probes. Gate выполняется один раз до DSI attach, не является проверкой PLL/link после modeset.
- Отключить автоматическое гашение экрана для первого теста; suspend/resume, DPMS и cold-start не реализованы.
- Подготовить SSH и сохранение логов до/после bind. MSM всё равно выключает/включает DSI PHY/host; исчезновение EFI изображения возможно. Нужен сохранённый рабочий пункт загрузки.

Успех аппаратного теста: создан DRM card, connector предлагает ожидаемый режим, атомарный modeset проходит, пользователь видит тестовую картинку, SSH остаётся доступен. Это ещё не проверка GPU/ускоренного Wayland.
