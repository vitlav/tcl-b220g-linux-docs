# Adreno 618: аппаратный GL и Vulkan

FD618 и Turnip Adreno 618 подтверждены аппаратно, Wayland GL/Vulkan тесты завершились. Файлы сборки этого каталога относятся к конкретному исследовательскому комплекту и требуют согласованных Image/DTB/modules/firmware.
