# Аудиоподдержка TCL B220G

[Спецификация аудиотракта](../../../../docs/hardware/audio.md) описывает ADSP/Q6ASM/Q6AFE, SoundWire, WCD9385, ресурсы, питание и необходимые патчи.

Слышимый звук и WCD9385 подтверждены аппаратно. Запись с микрофона и полная постоянная интеграция остаются открытыми. Каталоги рядом содержат исходники отдельных проверок; ранние конфигурации с dummy-кодеком не являются текущей спецификацией оборудования.

База AUDIO2 — модифицированный Linux 6.18.34, release `6.18.34-tcl-audio2`. Патчи имеют отдельные назначения и ограничения; их [каталог](../../../../patches/kernel/README.md) не является единой последовательной серией.
