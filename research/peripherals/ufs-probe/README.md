# UFS: ресурсы и проверка поддержки

[Спецификация UFS и ICE](../../../docs/hardware/storage.md): модель, шесть LUN, MMIO/IRQ/IOMMU, clocks, питание и подтверждённое чтение.

Сохранённые исходники и конфигурации этого каталога относятся к первоначальному подключению UFS без ICE. Работа ICE и текущие ограничения описаны в спецификации; начальный вариант DT не следует считать полным актуальным описанием ноутбука.
