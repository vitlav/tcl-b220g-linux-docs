# Интеграция Ubuntu Base для TCL B220G

[Спецификация Ubuntu: состав, firmware, службы, сеть и размещение rootfs](../../../docs/ubuntu.md).

## Исходники конфигурации

- [configure-root.sh](configure-root.sh) — настройки systemd, Qualcomm radio services, networkd, SSH и UFS read-only. Содержит фиксированные параметры исходной конфигурации; требует адаптации перед применением.
- [build-initramfs.py](build-initramfs.py), [build-boot.sh](build-boot.sh) — сборка загрузочных компонентов. Это части исследовательского комплекта, не самостоятельный воспроизводимый установщик.
- [grub.cfg](grub.cfg) — образец меню исходного комплекта; имена файлов и состав DT относятся к нему.

**Применимость:** Ubuntu Base 26.04.1 LTS ARM64. Образцы содержат ссылки на исходное ядро `6.18.34-stb-qc7+`; текущая рабочая конфигурация использует модифицированное ядро `6.18.34-tcl-audio2`. При переносе должны согласованно меняться Image, DTB, модули и initramfs. Текущая [поддержка устройств](../../../docs/status.md) описана отдельно.
