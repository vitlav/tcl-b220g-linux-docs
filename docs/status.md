# Проверенное состояние и следующие задачи

Срез: 2026-09-10. Текущий boot `4e6555b5-375b-4855-8672-59a720177a4c`, MEMDIAG на основе рабочего DT-ядра. SSH и Weston проверены active; это не проверка текущего воспроизведения звука или Venus.

| Подсистема | Доказано | Что остаётся |
|---|---|---|
| CPU | 8 CPU, cpufreq-hw, рабочая Linux DT-загрузка | EL2 не предоставлен firmware: Linux стартует в EL1, /dev/kvm нет |
| UFS | Накопитель доступен, архив всех 6 LUN проверен по SHA256 | Реальное восстановление Windows из архива не испытывалось |
| Wi-Fi | ath10k SNOC, постоянная настройка сети/SSH исследована; текущий доступ работает | Не считать настройку перенесённой в каждый новый initramfs без проверки |
| Графика | MSM/DPU + DSI + LT8911EXB handoff, Adreno/Wayland проверены | Устранение раннего чёрного экрана и полной зависимости от firmware handoff |
| Видео | Venus decode и программный decode сравнивались | Проверять наличие узла Venus и фактический декодер mpv, артефакты/плавность |
| Звук | WCD9385 variant=5, RX/TX SoundWire, слышимый звук | Стабильное повторное воспроизведение, щелчки, восстановление после ошибок |
| Камера | USB video-узлы обнаружены | Самостоятельное подтверждение изображения и режимов по сохранённым тестам |
| Микрофон | Части аудиотракта определены | Полноценная запись и физическая разводка не подтверждены |
| EC/батарея | Чтение состояния, подтверждена зарядка | Стандартный драйвер power_supply/lid |
| SAR AW96105 | Временный IIO-тест дал меняющиеся raw-значения | Питание vcc, постоянный DT/драйвер, назначение электродов |
| GNSS/LTE | Windows-устройства и OEM firmware найдены | Linux LOC/GPS fix, правильная прошивка/резерв памяти |
| ACPI | Живые таблицы считаны; DSDT совпадает с Windows | Рабочая загрузка, USB/сеть/дисплей; SCM/DMA/SMMU |

Ближайшая ACPI-работа: ранний CPIO с SCM `_CCA=0` проверен локально; подготовить диагностируемый загрузочный комплект, оценить побочные действия SCM probe, отдельно подготовить корректную Qualcomm-инициализацию двух разных SMMU. Новый загрузочный тест допускается только с заранее проверенным сбором диагностики и согласованием перезагрузки.

Обновление ACPI: [полный Image ACPI2 и 948 модулей собраны](../research/acpi-boot/acpi2/README.md), но не установлены. Следующие препятствия — [IORT input IDs и USB glue](../research/acpi-audit/iort-mappings/README.md); конфигурация диагностики остаётся условием следующей загрузки.
