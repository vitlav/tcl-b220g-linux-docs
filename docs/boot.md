# Загрузка: состав и совместимость компонентов

Проверенный путь — **UEFI → GRUB ARM64 → Linux Image + DTB + initramfs → Ubuntu на USB**. Внутренний накопитель UFS содержит Windows. [Организация rootfs](ubuntu.md#размещение-на-usb) и [поддержка ACPI](acpi.md) описаны отдельно.

## Загрузочный комплект

| Компонент | Требование |
|---|---|
| EFI loader | ARM64 removable path `EFI/BOOT/BOOTAA64.EFI` |
| GRUB | В исследованном комплекте меню встроено в EFI; отдельный grub.cfg не является активным источником меню |
| Image | Собственная сборка Linux с необходимыми драйверами TCL |
| DTB | Согласованные ресурсы, reserved memory, phandles и зависимости устройств |
| Initramfs | Драйверы носителя/rootfs, firmware для раннего запуска, init и диагностика |
| Modules | Соответствуют Image по release, конфигурации и ABI; одного имени файла недостаточно |
| Rootfs | Ubuntu 26.04.1 LTS ARM64 с настроенными службами Qualcomm, сетью и SSH |

Проверенные инструменты создания EFI — Debian GRUB 2.12 с соответствующими модулями arm64-efi. Версия executable и модулей должна совпадать. Встраивание меню — свойство данного комплекта, а не обязательное требование UEFI ноутбука.

Kernel release не всегда однозначно идентифицирует бинарник: диагностическая MEMDIAG-сборка сохраняет имя audio2 при изменённой конфигурации. Для точного соответствия нужны SHA256 Image/DTB/initramfs, .config и сведения о модулях.

## Ранний экран и удалённый доступ

Для ранней нативной консоли MSM и handoff-модуль LT8911EXB загружаются из initramfs до поиска Ubuntu rootfs. [Подтверждённые результаты и ограничения](hardware/display.md#ранний-вывод-и-проверка-3d). Консоль, compositor и графический вход пользователя — отдельные этапы.

Wi-Fi зависит от MPSS, RMTFS, QRTR, firmware и профиля подключения. [Последовательность служб](ubuntu.md#firmware-и-запуск-wi-fi). Настройка сети только в предыдущем образе не обеспечивает доступ из нового initramfs.

Слышимый звук после подготовки тракта подтверждён; автоматическая аудиоподготовка при загрузке ещё может завершиться ошибкой. Поэтому наличие enabled audio unit не считается подтверждением готовой ALSA-карты. [Аудиоинтеграция](hardware/audio.md).

## Диагностика и критерии проверки

- Проверяются синтаксис меню, наличие всех файлов и совместимость Image/DTB/modules/firmware до установки.
- Известный рабочий комплект сохраняется отдельным пунктом; изменение default/next_entry должно соответствовать выбранному комплекту.
- Носитель определяется по идентификатору и маркеру, а не букве sdX. Внутренний UFS и USB могут менять порядок регистрации.
- Сохранение логов подтверждается реальными файлами на USB, завершённой записью и повторным чтением. Наличие logger в initramfs не доказывает доступность USB после запуска ядра.
- Проверка каждого нового комплекта включает самостоятельный запуск rootfs, сети и SSH; успешная загрузка соседнего пункта не заменяет её.

MEMDIAG использует ограниченное чтение проверенного ACPI reserved RAM с отключённым STRICT_DEVMEM. Это диагностический вариант, не настройка постоянного ядра. MSDM payload исключён из сбора.

В ACPI-варианте USB/сеть ещё не подтверждены. Полная сборка ACPI2 сама по себе не образует готовый диагностируемый комплект: нужны согласованный initramfs и работающий канал сохранения результата.

## Firmware ранней графики и rootfs

[Проверка firmware внутри сохранённого AUDIO2 initramfs](../artifacts/initramfs-firmware-manifest.json) выполнена потоковым разбором всех 1270 CPIO entries. После TRAILER обнаружен только нулевой padding; других CPIO-архивов в распакованном потоке не найдено. В отчёт включены только firmware-пути, размеры и SHA256.

| Файл относительно lib/firmware | Байт | Сравнение с rootfs |
|---|---:|---|
| qcom/a630_gmu.bin | 32768 | Совпадает |
| qcom/a630_sqe.fw | 34188 | Совпадает |
| qcom/sc7180/tcl/qcdxkmsuc7180.mbn | 14256 | Совпадает |

Других файлов в lib/firmware или usr/lib/firmware этого initramfs нет. Это согласуется с ранним KMS; WLAN/MPSS, ADSP, Venus и SAR представлены в [каталоге firmware rootfs](firmware.md#полная-инвентаризация-установленного-каталога). Наличие файла в архиве не доказывает факт его загрузки устройством.

Проверенный сжатый initramfs имеет размер 14952280 байт, SHA256 `3c196074a0602c528840711587fefbb3a39b196a1f81affd2ec8641959de071c`. Это идентификация прочитанного файла на USB, не независимое доказательство побайтной идентичности образа, переданного ядру при предыдущем старте.

При обновлении firmware GPU следует отдельно согласовать раннюю копию в initramfs и копию rootfs. Установка DEB в rootfs не обновляет автоматически этот вручную подготовленный USB-образ: в проверенной системе нет обработчика initramfs-tools. Для остальных подсистем не следует предполагать наличие firmware до монтирования rootfs только потому, что файл установлен в Ubuntu.

## Идентификация комплекта MEMDIAG

[Манифест загрузочных файлов](../artifacts/memdiag-boot-files.json) фиксирует прочитанные на USB Image, DTB и initramfs, а также сумму сохранённой конфигурации ядра. Release `6.18.34-tcl-audio2` общий с базовым AUDIO2, поэтому для различения комплектов нужны эти суммы.

| Объект | Байт | SHA256 |
|---|---:|---|
| MEMDIAG Image | 32074240 | `78c251e585d082d221b17429769b4ad861e9aeb23ef64e5249029610ca059ef5` |
| AUDIO2 VA DTB | 79287 | `f795878b99d960c253b2b2cd994cbe29e15b7f2aed2e9da169c63cb807de1dd0` |
| AUDIO2 initramfs | 14952280 | `3c196074a0602c528840711587fefbb3a39b196a1f81affd2ec8641959de071c` |

[Модули внутри initramfs](../artifacts/initramfs-module-manifest.json): все **949 обычных файлов модулей** совпали по размеру и SHA256 с соответствующими путями rootfs. Отсутствующих и отличающихся файлов в этой выборке нет. Проверка выполнена без загрузки/выгрузки модулей и без изменения носителя.

Сверка устанавливает согласованность копий на диске. Она не проверяет байты уже загруженного в память модуля, все внешние диагностические модули, расположенные вне этого набора, ABI каждого будущего ядра или соответствие текущему исходному Git commit. Файл на USB также не является независимым доказательством того, какие байты загрузчик передал при предыдущем старте.
