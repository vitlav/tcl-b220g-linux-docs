# Ubuntu: состав системы и требования к интеграции

Пользовательское окружение — **Ubuntu 26.04.1 LTS ARM64**, на основе Ubuntu Base. Рабочая конфигурация использует Device Tree и модифицированное ядро `6.18.34-tcl-audio2`. Поддержка оборудования определяется ядром, DT, firmware и службами Qualcomm.

**Проверено на оборудовании:** запуск Ubuntu/systemd, Wi-Fi, DHCP, DNS и SSH; графика, видеодекодирование и звук — в конфигурациях, указанных в [сводке подсистем](subsystems.md). Стандартное ядро Ubuntu на этом ноутбуке не подтверждено. Готовой воспроизводимой установки с чистой базы одной командой пока нет.

## Исходная база

| Компонент | Спецификация |
|---|---|
| Root filesystem | Ubuntu Base 26.04.1 LTS, ARM64 |
| Исходный архив | `ubuntu-base-26.04.1-base-arm64.tar.gz` |
| SHA256 архива | `5a1906794ced63a71a8119c3f211ef5f0bbe0a243001b4bbd41fdf80c5b219fd` |
| Init / службы | systemd, udev, D-Bus |
| Ядро | [Конфигурация и патчи TCL](kernel-and-ubuntu.md); модули должны соответствовать Image |
| Описание устройств | DTB TCL; [ресурсы и связи](hardware/device-summary.md) |
| ACPI | [Отдельная конфигурация](acpi.md), полноценная загрузка не подтверждена |

Происхождение архива и проверка его суммы зафиксированы при подготовке базы. Полный актуальный пакетный манифест в публичном комплекте пока отсутствует.

## Обязательные компоненты пользовательского окружения

| Назначение | Компоненты | Требование |
|---|---|---|
| Запуск системы | systemd-sysv, udev, dbus, kmod | PID 1 — systemd; depmod для установленного kernel release |
| WLAN | wpasupplicant, iw, iproute2 | ath10k SNOC и firmware должны создать интерфейс до подключения к точке |
| DHCP | systemd-networkd | DHCP настроен здесь; отдельный dhcpcd для этой конфигурации не требуется |
| DNS / время | systemd-resolved, systemd-timesyncd | DNS от DHCP; синхронизация времени после появления сети |
| Qualcomm firmware services | rmtfs, tqftpserv, qrtr-tools | Службы и reserved memory готовы до запуска MPSS |
| Удалённый доступ | OpenSSH server/client/SFTP | Собственные host keys и authorized_keys для каждой установки |
| USB loop-root | btrfs-progs; loop/Btrfs в ядре или initramfs | Требуется только для описанного ниже размещения rootfs |
| Диагностика | iputils-ping, i2c-tools, ca-certificates | EC пока читается отдельным инструментом; это не стандартный power_supply |

Пакеты в обслуживаемой системе устанавливаются через epm. Графический стек, Firefox и аудиосервер добавляются отдельно; их наличие не является свойством Ubuntu Base.

Ресурсы контроллера, питание и проверенные радиорежимы: [спецификация Wi-Fi](hardware/wifi.md).

## Firmware и запуск Wi-Fi

[Состав и манифест firmware](firmware.md) фиксируют проверенный архивный поднабор и оставшиеся пробелы.

WLAN зависит от Qualcomm MPSS, QRTR и доступа firmware к собственным данным. Одного `modprobe ath10k_snoc` недостаточно для описания всей последовательности запуска.

| Объект | Требование |
|---|---|
| MPSS | OEM TCL `qcom/sc7180/tcl/qcmpss7180_nm.mbn` в используемой конфигурации |
| WLAN DSP | OEM TCL `wlanmdsp.mbn` и согласованный набор сопутствующих файлов |
| ath10k | Firmware API-файл и board/calibration для WCN3990/TCL; соответствие конкретному устройству обязательно |
| Regulatory database | regulatory.db и соответствующая подпись |
| RMTFS reserved memory | Физический адрес `0x80600000`, размер `0x200000` в описанной DT-конфигурации |
| Modem storage | Индивидуальные копии modemst1/modemst2/fsg/fsc; не общий набор для всех ноутбуков |
| RMTFS | `rmtfs -r -v -o /rmtfs-storage`; копии и RAM shadow writes вместо записи внутренних служебных разделов |
| tqftpserv | TFTP поверх QRTR для Qualcomm firmware; не служба сетевой загрузки ОС |
| Готовность служб | QRTR service 14 и RMTFS memory проверяются до запуска MPSS |

Реализация порядка запуска в [configure-root.sh](../research/peripherals/ubuntu-base/configure-root.sh): `tcl-radio.service` зависит от rmtfs/tqftpserv и предшествует `wpa_supplicant@wlan0`. Автоматическая загрузка qcom_q6v5_pas и ath10k_snoc ограничена blacklist, затем модули загружаются явно. Используется nameserver ядра; отдельный qrtr-ns отключён. Remoteproc recovery отключён в этой конфигурации.

Этот скрипт — образец исходной интеграции: он содержит фиксированные значения конкретной установки, включая MAC и kernel release, и не является универсальным установщиком. Полный перечень firmware с происхождением и применимостью ещё требуется свести в единый переносимый манифест.

## Сеть и доступ

| Настройка | Значение / условие |
|---|---|
| Имя WLAN | `wlan0` в текущих unit-файлах; имя должно совпадать в networkd и wpa_supplicant |
| Networkd | `.network` и `.link` доступны для чтения systemd-network: файлы `0644`, каталог `0755` |
| WPA profile | `/etc/wpa_supplicant/wpa_supplicant-wlan0.conf`, права `0600`; credentials задаются индивидуально |
| DHCPv4 | `ClientIdentifier=mac`, `RouteMetric=100` для WLAN |
| USB tethering/Ethernet | Отдельный DHCP-профиль, `RouteMetric=500`; дополнительный путь подключения |
| SSH | Вход по ключам; парольный и keyboard-interactive вход отключены |
| Socket activation | `ssh.socket`, IPv4 port 22; отсутствие постоянного sshd до подключения допустимо |

Фиксированный MAC из исходного образца не является аппаратным требованием и не должен тиражироваться. Телефон для основного WLAN не требуется. Проверка сети в уже запущенной системе и проверка автоматического подключения после загрузки — разные критерии; для нового образа проверяются оба.

## Размещение на USB

UEFI → GRUB ARM64 → Image + DTB + initramfs → Ubuntu. Применяемый способ размещения позволяет сохранять внутренний Windows-накопитель:

| Слой | Описание |
|---|---|
| Загрузчик | `EFI/BOOT/BOOTAA64.EFI`, конфигурация GRUB встроена в EFI |
| USB filesystem | FAT32, содержит загрузочные файлы и `/tcl-ubuntu/rootfs.img` |
| Корень Ubuntu | Btrfs в loop-образе; размер каждого файла FAT32 должен быть меньше 4 GiB |
| Initramfs | Находит носитель, монтирует FAT32, подключает loop и Btrfs, передаёт управление `/sbin/init` |
| Выключение | Возврат в initramfs, размонтирование rootfs, отсоединение loop, размонтирование внешнего filesystem |
| Внутренний UFS | Не включён в fstab; в диагностической конфигурации принудительно read-only |

FAT32/Btrfs loop-root — выбранная организация носителя, а не требование SC7180. Идентификатор USB, размер rootfs и метка filesystem также не свойства ноутбука. Для другого носителя необходимо адаптировать механизм его обнаружения. Процедура shutdown описана в реализации; её наличие само по себе не подтверждает безопасное завершение каждого варианта образа.

Для сборки EFI используются согласованные инструменты и модули GRUB ARM64. Проверенная версия — Debian GRUB 2.12. [Загрузка и диагностические требования](boot.md).

## Границы поддержки

- Ubuntu Base не включает драйвер EC/power_supply для TCL; доступные поля и протокол описаны отдельно.
- Аппаратные GPU, Venus и аудиотракт требуют соответствующих DT/ядра и пользовательского стека; ограничения ранней консольной конфигурации не описывают их текущую поддержку.
- Работа одного комплекта не подтверждает другой набор Image/DTB/initramfs/modules/firmware. Для воспроизводимости нужны версии, конфигурации и контрольные суммы всех этих компонентов.
- Персональные Wi-Fi, SSH и modem storage не входят в публичный комплект документации.
