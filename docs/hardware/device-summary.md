# TCL B220G: полный реестр живого Device Tree — 2026-09-10

Источник: `/sys/firmware/devicetree/base`, boot `4e6555b5-375b-4855-8672-59a720177a4c`, ядро `6.18.34-tcl-audio2`. Дерево снято после загрузки, поэтому включает применённые изменения OF. Привязки драйверов сняты отдельно в той же загрузке. Исходный архив SHA256 `1efdc9b902c8e350081824c91414224c6eb2b44dc0dd73d61b4c2b97f1b30890`.

Это полный реестр **описания DT**, а не доказательство наличия каждого блока на плате. `okay` означает разрешённый узел; привязанный драйвер не гарантирует работоспособности всех функций. `disabled` и отключённые предки указаны явно. Отсутствующее свойство не заменено предположением. Устройства, перечисляемые USB, SoundWire или firmware динамически, могут не иметь отдельного DT-узла.

Адрес `reg` интерпретирован по `#address-cells/#size-cells` родителя: для MMIO показаны адрес и размер, для I²C — адрес ведомого. Адреса остаются в адресном пространстве родительской шины; преобразования `ranges` сохранены в полном перечне. SPI/PPI — номера DT, INTID — архитектурный номер GIC, **не Linux IRQ**. Флаги IRQ: 1 rising, 2 falling, 4 level-high, 8 level-low. GPIO specifier — линия/флаги провайдера (обычно 0 active-high, 1 active-low); смысл прочих числовых specifier определяется binding соответствующего контроллера. Напряжения — в µV, частоты clocks/OPP — в Hz, drive-strength — в mA; это заданные ограничения, не измерения. Phandle разрешён до полного пути. Pinctrl, OPP, регуляторы, endpoint и reserved-memory вынесены отдельными строками, чтобы не терять зависимости.

## Физические устройства и сведения вне текущего DT

| Устройство | Что известно; граница достоверности |
|---|---|
| Матрица / подсветка | Вывод 1920×1080 проверен ранее. В текущем DT мост LT8911EXB использует handoff; самостоятельного полного panel/backlight-описания с измеренными напряжениями нет. Не подменять настройки firmware догадками. |
| WCD9385, динамики / аналоговый тракт | WCD9385 идентифицирован ранее по CHIP_ID variant=5; звук из динамиков подтверждён пользователем. Часть связей добавлялась диагностическими модулями, поэтому этот DT не является полным готовым описанием аудиоплаты. Подробные GPIO58 reset, RX/TX и питание — в материалах camera-audio/audio2; не переносить их сюда как якобы присутствующие свойства. |
| Микрофон | Физическая разводка аналоговых входов/DMIC и полноценная запись не доказаны наличием VA macro; нужны отдельные результаты capture. |
| Камера | Ранее обнаружена USB-камера, /dev/video0 и /dev/video1. USB-устройства не обязаны иметь DT-узлы: GPIO/напряжения сенсора из этого дерева не извлекаются. Два video-узла не означают две камеры. |
| EC / батарея / адаптер | В DT есть I²C@0x888000, 400 kHz. EC адрес 0x07 известен из ACPI и предыдущих проверок чтения; отдельного EC-клиента/стандартного power_supply-драйвера в этом DT нет. Зарядка и рост ёмкости ранее проверены. Связанная задача #19490. |
| Датчик крышки | ACPI PNP0C0D; состояние ELID читается через EC, бит 0x80 в байте 1 полезной нагрузки. Отдельный GPIO и DT-узел lid в текущем дереве не описаны; не считать его SAR-датчиком. |
| AW96105 SAR / приближение тела | I²C@0x890000, адрес 0x12, GPIO34, EdgeBoth/PullUp получены из ACPI; ранее работал временный IIO-драйвер aw96103 с OEM-конфигурацией. В текущем DT отдельного узла нет; vcc/физическое расположение электродов не установлены. |
| GNSS / GPS | Исследуется в #19500. Отдельного GNSS-узла в текущем DT нет. Windows inventory содержит Qualcomm Location (QCOM0872), OEM GNSS firmware исследована; Linux GPS fix не получен. |
| Bluetooth | Отдельного Bluetooth-узла в текущем DT нет; совместимость семейства WCN3990 сама по себе не доказывает подключение и работоспособность Bluetooth на ноутбуке. |
| Акселерометр, гироскоп, компас, датчик освещённости | Отдельных узлов в текущем DT нет; прежний поиск по Windows не подтвердил эти устройства. Это не доказательство физического отсутствия. |
| Ethernet / SIM | Пользователь уточнил, что встроенного Ethernet нет. USB tethering проверялся как внешнее устройство. DT не устанавливает наличие SIM-разъёма. По сохранённому исследованию спецификация TCL указывает Nano SIM + TF, а Windows inventory содержит Snapdragon X15 LTE; Linux LTE-сеанс не проверен. |

Числовые clock/reset/domain ID сохранены точно; их символические имена определяются заголовками bindings используемого ядра.
