# Датчики: AW96105 и состояние крышки

## AW96105: назначение и ресурсы

AW96105 — ёмкостный датчик SAR/proximity. OEM Windows конфигурация связывает его каналы с радиоподсистемой: SUBSYS_27822600, NumberOfChannels=5, WlanAntCount=2, channel0=MODEM, channel1–4=WLAN, WlanAntMask=3. Это не устанавливает расположение электродов и не доказывает назначение для выключения экрана при приближении лица.

| Ресурс | Значение / подтверждение |
|---|---|
| OEM ACPI | SAR1, HID AWDZ9610X |
| I²C controller | ACPI I2C5, MMIO 0x890000; номер Linux-адаптера динамический |
| Адрес датчика | 0x12 |
| IRQ pin | GPIO34, EdgeBoth, PullUp по ACPI; применено в тесте |
| CHIPID | 0xa9610b00, прямое чтение |
| FWVER2 | 0x20000000, прямое чтение |
| Драйвер | aw96103.c, IIO name aw96105_sensor |
| Питание vcc | Источник не установлен; в тесте dummy regulator, физическое питание не переключалось |

Полный ACPI match AWDZ9610X отсутствует в изученном драйвере; тестовый клиент использует I²C/OF matching. Временное подключение не является постоянным DT-описанием.

## Конфигурация из firmware

Из SAR1._DSM function2 извлечён OEM-блок **892 байта**: проверены строка AW96105, контрольная сумма 0x7139, длина данных 832 байта и 138 пар register16/value32. SHA256: `7a7be16421d74b963a73bc7a4c0c16fae90af4fb306c49762ad612acdbe526f4`.

Имя файла, ожидаемое изученным драйвером, — `aw96103_0.bin`, в том числе для AW96105. Это конфигурация регистров, а не исполняемый код. SCANCTRL0=0x1f1f включает пять каналов, IRQEN=0x206. Число включённых каналов не доказывает число физических электродов.

В изученной реализации отсутствие firmware завершает callback без запуска встроенной конфигурации. Поэтому наличие IIO-узла само по себе не подтверждает запущенные измерения. [Сохранённый драйвер](../../research/peripherals/sensors/aw96103.c).

## Аппаратный результат и ограничения

На ядре `6.18.34-tcl-audio2` с OEM-конфигурацией появились шесть raw-каналов 0–5; каналы 0–4 включены, канал5 отключён. Значения меняются: например, `139, 22, 175, 4194295, 8, 0` и `125, 53, 171, 25, 17, 0`.

Это подтверждение работы измерительного тракта. Реакция на приближение тела, карта электродов, пороги и практические IRQ-события не проверены. В наблюдаемом интервале счётчик IRQ оставался нулевым; отсутствие шторма не подтверждает работу прерываний.

Значения около 2^22 требуют проверки знака: код делит u32 data на 1024 до приведения к int. Raw нельзя интерпретировать как сантиметры. Роль шестого внутреннего канала и формат конкретной ревизии остаются открытыми.

Для постоянной интеграции нужны подтверждённый vcc provider, pinctrl/IRQ, жизненный цикл firmware callback и клиента, проверка преобразования значений и физических событий. [Тестовый клиент](../../research/peripherals/sensors/tcl_sar_client.c) удерживает ресурсы до перезагрузки и не является готовым драйвером платы.

## Крышка и другие датчики

Крышка читается через поле ELID контроллера EC; [протокол и требуемый SW_LID](ec.md). Отдельная физическая проверка открытия/закрытия не подтверждена. Вопросы SAR и крышки связаны с задачей [19501](https://bugs.etersoft.ru/19501).

Доказательств работающего акселерометра, гироскопа или датчика освещённости в этих результатах нет. Наличие датчиков в семействе платформы или Windows-класса устройства само по себе не устанавливает их наличие и подключение на TCL.
