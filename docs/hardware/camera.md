# Встроенная камера USB UVC

**Проверено на оборудовании:** обнаружение USB UVC `13d3:784b` и живое изображение камеры в Weston; пользователь подтвердил картинку.

| Параметр | Подтверждение |
|---|---|
| Интерфейс | USB Video Class |
| Capture | V4L2 capture-узел, сопутствующий video-узел и media device |
| MJPEG | Перечислен режим 1280×720 @ 30 fps; использован для показа |
| YUYV | Перечислен режим 1280×720 @ 5 fps |
| Другие режимы | Перечислены меньшие разрешения @ 30 fps; полная матрица тестов отсутствует |
| Вывод | ffplay в Weston, MJPEG decode и преобразование цвета программные |

Номера /dev/videoN не постоянны и меняются при подключении Venus и других устройств. Выбирать камеру следует по USB identity и V4L2 capabilities. VID:PID не устанавливает модель сенсора внутри камеры.

Предупреждения ffplay о APP fields и отсутствии ускоренной конверсии yuv422p→rgba зафиксированы; они не помешали подтверждённому изображению. Измеренная частота кадров, длительная устойчивость, все controls, suspend/resume и работа камеры в браузере не проверены.

Камера не является подтверждением работы [Venus](video.md). Наличие UVC-камеры также не доказывает работающий микрофон — [аудиозахват](audio.md#микрофон-и-завершение-интеграции) остаётся отдельной задачей.
