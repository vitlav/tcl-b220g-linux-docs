# Firmware: состав, происхождение и применимость

[Манифест firmware](../artifacts/firmware-manifest.json) содержит 20 сохранённых бинарных файлов: размеры, SHA256, путь в исходном архиве и известный путь установки относительно каталога firmware. Размеры и контрольные суммы повторно проверены по самим архивным файлам. Бинарники в Git не включены.

Это проверенный поднабор архива, а не полный манифест установленной системы. Проверка SHA256 устанавливает идентичность файла; она не подтверждает его выбор драйвером, успешную аутентификацию DSP или работу всех функций.

## Назначение файлов

| Группа | Состав / происхождение | Применимость |
|---|---|---|
| WLAN / MPSS NM | 16 OEM TCL файлов: `qcmpss7180_nm.mbn`, `wlanmdsp.mbn`, 14 вариантов `bdwlan*`/`bdwlanu*` | Сохранённый Windows DriverStore набор; работа WLAN подтверждена, загрузка каждого варианта board не установлена |
| Venus | `qcom/venus-5.4/venus.mbn`, 922376 байт | Проверенная версия VIDEO.VE.5.4-00064-PROD-1; ограничения декодирования сохраняются |
| ADSP | `qcom/sc7180/tcl/b220g/qcadsp7180.mbn`, 13463676 байт | OEM Windows ADSP package, используется проверенным аудиотрактом |
| GPU | `qcom/sc7180/tcl/qcdxkmsuc7180.mbn`, 14256 байт | OEM Windows graphics package, входит в проверенную конфигурацию GPU |
| Полный MPSS | `qcmpss7180.mbn`, 61815992 байт | OEM Windows MPSS package; кандидат для исследования GNSS/LTE, аппаратно не проверен |

Архивные пути в JSON определяют происхождение сохранённой копии; это не пути назначения в Linux. Для полного MPSS путь установки намеренно не задан: резерв рабочей NM-конфигурации не подходит для этого образа. [Различия MPSS и требования к памяти](hardware/modem.md).

## Файлы работающей системы

[Манифест установленного поднабора](../artifacts/firmware-runtime-manifest.json) получен чтением файлов работающей DT/MEMDIAG-системы 2026-09-10. Он дополняет архивный манифест, но не заменяет полный перечень firmware. Канонический каталог — `/usr/lib/firmware`; `/lib/firmware` разрешается в него.

| Файл относительно каталога firmware | Байт | Подтверждение |
|---|---:|---|
| `qcom/a630_sqe.fw` | 34188 | Размер и SHA256 прочитаны из установленного файла |
| `qcom/a630_gmu.bin` | 32768 | Размер и SHA256 прочитаны из установленного файла |
| `ath10k/WCN3990/hw1.0/board.bin` | 26328 | SHA256 совпадает с архивным OEM `bdwlan.bin` |
| `ath10k/WCN3990/hw1.0/firmware-5.bin` | 60 | SHA256 совпадает с ранее сохранённой суммой API-файла |
| `regulatory.db` | 6380 | Размер и SHA256 прочитаны из установленного файла |
| `regulatory.db.p7s` | 1085 | Размер и SHA256 прочитаны из установленного файла |

Полные SHA256 приведены в JSON. Dpkg не нашёл владельцев этих шести файлов ни по `/lib`, ни по `/usr/lib`. Пакет `linux-firmware` отсутствует в базе, `wireless-regdb` имеет состояние `un` (не установлен). Следовательно, переустановка только этих пакетов не является документированным способом восстановить точный проверенный набор. По отсутствию владельца нельзя установить источник бинарника или способ его первоначального копирования.

Чтение файла не доказывает его фактическую загрузку драйвером. Для board data ещё требуется сопоставление runtime board ID с выбранным файлом; для regulatory database — отдельная проверка применения и подписи, а не только её наличия. Версии и происхождение GPU/API/regulatory-файлов ещё надо связать с конкретными исходными пакетами или upstream revision.

`aw96103_0.bin` — OEM SAR register configuration; отдельный формат и происхождение описаны в [спецификации датчиков](hardware/sensors.md). Это не исполняемая DSP firmware и пока не часть этих двух манифестов.

## Индивидуальные данные и порядок запуска

`modemst1`, `modemst2`, `fsg`, `fsc` — индивидуальные данные экземпляра для RMTFS, а не общий распространяемый набор firmware. Их нельзя подменять данными другого ноутбука. В проверенной конфигурации RMTFS работает с копиями и RAM shadow writes; внутренние служебные разделы не используются для записи.

[Ubuntu: firmware и службы](ubuntu.md#firmware-и-запуск-wi-fi) описывает последовательность RMTFS/tqftpserv/MPSS/WLAN. Наличие файлов без правильной карты памяти, SCM, remoteproc и служб недостаточно для запуска. [WLAN](hardware/wifi.md), [GPU](hardware/display.md), [Venus](hardware/video.md) и [аудио](hardware/audio.md) имеют отдельные зависимости и критерии проверки.

Для нового комплекта следует дополнить этот поднабор манифестом реально установленных файлов и пакетов, сохранить соответствие firmware-name из DT и проверить загрузку каждой нужной подсистемы. Права распространения OEM-файлов этим каталогом не устанавливаются.
