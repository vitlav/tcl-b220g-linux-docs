# Системные настройки DT

Существующие инструкции: [Ubuntu](../../docs/ubuntu.md), [ядро и система](../../docs/kernel-and-ubuntu.md), [DT-аудио](../../docs/hardware/audio.md). Отдельный полный root-overlay для DT пока не выделен. В рамках упорядочения каталогов настройки системы не изменяются и DT не испытывается.
