# Архив исходных материалов

`manifest.json` перечисляет **2429 исходных файлов** из `.claude/docs/tcl-b220g-data/`: относительный путь, размер и SHA256. Общий объём около 673 MiB. Для перенесённых в Git текстов есть путь `git` и SHA256 итогового файла; нормализация завершающего перевода строки может менять hash относительно оригинала.

Исходная полная коллекция находится в административном workspace:
`/srv/lav/Projects/git-eter/etersoft-admin-essential/.claude/docs/tcl-b220g-data/`.

Рабочий внешний архив: `/var/ftp/tmp/lav/tcl/`. Его тематические каталоги формировались по ходу работы, поэтому путь из манифеста не всегда напрямую совпадает с FTP-путём. Отдельный каталог `source-archive-20260910/` сохранён как точная копия дерева манифеста. Все 2429 файлов проверены чтением архива и сравнением SHA256 2026-09-10.

Образы ядра/EFI, DTB, модули, firmware, OEM Windows-драйверы, фото и полные сырые логи оставлены вне Git. Манифест позволяет проверить их происхождение и целостность. Проприетарные материалы не получают новой лицензии от включения в архив.

Архив Windows существенно больше этой коллекции и хранится отдельно: `/var/ftp/tmp/lav/tcl/windows-ufs-20260908/repository`, Borg 1.x, шесть LUN. Извлекаемость и SHA256 проверены; запись обратно и последующая загрузка Windows из восстановленного архива не испытывались. См. [инструкцию](../research/peripherals/windows-backup/README.md).
