# Происхождение и контрольные суммы материалов

[manifest.json](manifest.json) фиксирует снимок исходной коллекции от 2026-09-10: **2429 файлов**, около673 MiB. Для каждого исходника указаны относительный путь, размер и SHA256; поле git указывает путь первоначального импорта, если файл переносился в репозиторий.

## Область применимости манифестов

| Манифест | Что проверяет |
|---|---|
| artifacts/manifest.json | Исходный архив и состояние первоначального импорта |
| [Патчи ядра](../patches/kernel/manifest.json) | Точные байты текущих каталогизированных патчей, происхождение и статус |
| [ACPI2](../research/acpi-boot/acpi2/manifest.json) | Конкретную сборку Image, конфигурации и комплекта модулей |
| [Архивный поднабор firmware](firmware-manifest.json) | 20 файлов с происхождением, размерами и SHA256; не полный комплект установки |
| [Установленный поднабор firmware](firmware-runtime-manifest.json) | Файлы, прочитанные из работающей DT-системы; присутствие не доказывает загрузку драйвером |
| [OEM WLAN](../research/peripherals/wifi-services/firmware-sha256.txt) | Сохранённый набор OEM-файлов, не выбор каждого файла firmware во время запуска |

Документация после импорта редактируется, часть исторических текстов вынесена из актуального дерева. Поэтому git-пути и hashes исходного манифеста не являются перечнем обязательных файлов текущего checkout. Их нельзя использовать для проверки всей актуальной документации без учёта версии. Историю изменений файлов фиксирует Git.

Исходный архив побайтно проверен по всем2429файлам. Бинарные Image/EFI, DTB, модули, OEM Windows-драйверы, firmware, фотографии и сырые материалы хранятся отдельно. Включение файла в архив не меняет его лицензию и не означает готовность к публичному распространению.

Архив внутренних UFS LUN — отдельный набор персональных данных. [Охват и степень проверки](../research/peripherals/windows-backup/README.md): полное извлечение и SHA256 подтверждены, восстановление Windows не испытано. Он не входит в публичный установочный комплект.
